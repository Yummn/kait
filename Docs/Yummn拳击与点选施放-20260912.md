# Yummn 拳击与点选施放调整

## 本次规则

- 删除原无甲防御（O04/Tranquility）。闪身防御（R06/WaitingGuard）改名无甲防御，保留等待抵挡首次伤害的效果。新池37张，Kait牌池不变。
- 等待固定补一枚2，同时推进一次敌方阶段。静谧心境不重复追加；反击击杀另按本局击杀补给计算。没空格不积欠。
- 伺机而动检查敌人进入四邻范围的事件，包括人物位移、敌人主动移动/被推动及出生。持续相邻不重复触发；每名敌人同次操作至多反击一次，防止推掌/跟进形成无限递归。
- 反击进入统一拳击流程，可以触发疾风连击、火蛇之牙、震慑、冻结、推掌等联动。
- 疾风连击一次支付2气替代普通拳气费，连续两拳逐次结算。目标死亡或超出近身范围且不能跟进时停止后续拳。不足2气按普通一拳处理（已提出补充问题，未获另选前采用推荐默认）。
- 每段实际位移的起点留残影，包括气竭、击杀跟进、追身步、传送。连续滑行只留该段起点，不逐格堆叠。耐受与敌方阶段末清除规则不变。

## 操作与画面

- Yummn所有主动牌选择后，都显示人物上/右/下/左四个“施放”按钮。点选对应方向才能执行；场景相邻格也可点选。
- 冰柱、暗幕、诱饵改为相邻空格；影步等仍按所选方向寻找合法落点。治疗也要点选确认。
- 选目标期间，方向键、手机滑动、长按连发和等待不会执行移动/等待。
- 目标错误或气不足：不扣气、不推进回合，弹出释放失败原因，并退出选目标，重新选牌可重试。
- 放大卡牌标题/效果/气费与教程详细说明，扩展卡牌效果文字区域，不改2048数字。
