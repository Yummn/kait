# 后续特效

卡片相关全部暂缓。金角碎光、翠叶流光仅保留预览，待卡片机制和外观调整后再决定。

盾骑士：新增常驻正面指示，跟随实际 facing 四向变化；正面免伤时护面亮起、短促收紧，侧背受伤保留正常命中反馈。提示应在格内，避开脸部与血条，死亡后清除。当前 A 金弧护面、B 三片盾阵为预览，待选。

之后依次制作并预览：

1. 治疗／生命恢复：少量绿金光点收拢，与真实恢复量和血条变化同步。
2. 裂隙预警：只在即将出怪时沿边缘脉动，兼顾人物站在裂隙上的情况。
3. 胜利／失败：配合现有角色动作做克制收尾。
4. 跨盘联动：按实际规则事件连接来源格与落点，短暂提示后消退。

每组先给可选预览，再按选定方案接入和检查 Windows 实机效果。
