# 卡面简约边框裁切

问题是卡面外圈的稀有度细边由独立图形绘制，没有使用全局画风分界线，因此进入卡通侧后仍然叠在图片边框之外。

现在主动卡、被动卡都把同一个分界线传给细边。细边按实际三角形裁切：卡通侧不绘制，简约侧保留，跨线时只显示线右侧的部分。拖动、缩放及倾斜时重新计算局部交点，不增加遮罩或点击层。卡通卡面自身的边框、稀有度颜色和图标样式保持不变。

选牌槽位的绿色轮廓是操作提示，继续完整显示，不跟随卡面边框一起隐藏。
