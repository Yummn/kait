# 可移动选牌控制栏

拖住控制栏左侧的牌数区域即可移动。四个操作按钮不充当拖动把手，避免拖动时误触跳过或重抽。

位置在本局的奖励刷新、收起与展开之间保留；控制栏限制在界面范围内。卡牌与槽位不会跟随控制栏移动。

沿用全局斜线裁切：左侧浅色画框与蓝金按钮，右侧简约深色底板。每个按钮只有一个输入对象，按下状态统一；浅色底板上的牌数自动切换深色字，两个深色按钮样式都保留浅色字以保证对比。
