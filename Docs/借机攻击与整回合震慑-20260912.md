# 借机攻击与整回合震慑

## 借机攻击

新增独立罕见被动，稳定编号 R40，正式牌池变为38张；伺机而动保留。

- 伺机而动：进入四邻攻击范围时反击。
- 借机攻击：敌人离开四邻前出拳，包括被推动。Yummn自己远离敌人不触发。
- 两种反击各对每个敌人每次操作最多触发一次，防止推动、跟进形成无限递归。
- 使用统一拳击，可联动疾风连击、火蛇之牙、震慑等。离开前被击杀的敌人不再移动。
- 卡框为被动外观，蓝色罕见；复用现有获批反击图标，极简标记为“离”。

## 震慑拳

首次命中存活且未震慑的目标，额外消耗1气。立即取消攻击预警，保持震慑到一个完整敌方阶段结束；下一敌方回合恢复正常。若在敌方阶段内施加，则覆盖该阶段剩余时间。

期间再次拳击不会重复施加震慑、刷新期限或扣震慑费用。疾风连击自身的2气费用不受影响。没有推进敌方阶段的连续操作不会提前解除震慑。
