# v0.9.23 Kait 简洁卡图

## 设计约束

上一版卡图包含过多人物、铠甲细节和环绕粒子，缩到卡牌尺寸后主体不易辨认。本次以用户提供的Yummn卡牌大全截图为参考，逐张生成47个简洁图标。只在次级幻影、拟像术与列维斯图斯之墓使用简化Q版Kait，其余使用物件或法术符号。

角色固定为黑紫发、猫耳、琥珀眼和紫黑咒剑士衣领。图标使用大色块、粗深紫轮廓、青绿/紫/米白/金配色，透明底，不绘制卡框和文字。

## 生成方式与提示词

使用内置image_gen，每张独立生成；参考用户的Yummn截图。公共提示词：

```
Create ONE transparent game skill icon matching the supplied Yummn card icons in simplicity. NOT a character splash illustration. Flat cartoon large color shapes, bold dark plum outline, 5-7 main colors, only ONE hard-edged shadow per material. One main object and at most two small supporting shapes. Clean readable silhouette at 128 pixels. No filigree, tiny details, texture, particle shower, swirling ornament wreath, dramatic lighting, realistic rendering, gradients, full scene, frame, lettering or watermark. Genuine alpha transparent background, generous clear margin. Teal, muted violet, cream and warm gold palette. Keep the main object large and the composition simple. Unless the scene explicitly requests a character, NO people, faces, hair, heads or humanoid figure. Scene: 
```
