# 气竭移动补2

2026-09-10，按补充要求修改。此条覆盖原v0.8.1的纯击杀供给限制。

- 以动作开始时的状态判断。气竭状态实际移动（含传送）固定请求补一枚2；最后一步回满气也算。
- 原地出拳，以及出拳后的击杀跟进、推掌跟进，不算移动。
- 默认模式：移动补给与击杀补给分别计算。例如移动后反击击杀一名敌人，一共补两枚2。
- 替代模式：原本已有的移动补给不重复叠加，一次移动仍补一枚。
- 无踪步不取消这项固定补给。无效操作不补；无空位记丢弃；人物死亡或Boss胜利时不追加供给。
- 高速供给和敌方阶段条件保持不变。教程与设置说明同步更新。

新规则标记保存在每局快照中，成绩单独分组。旧局为保证回放一致性保持旧规则；新开Yummn局生效。此前四组断供报告是旧供给规则的基线，不代表本修订结果；新规则下不能再因没有重复数字就认定永久断供。

此次不自动重打安卓包；已生成的kait-v0.8.1.apk仍是上一次规则。

验证：626项自动化测试全部通过，含10个新增用例，覆盖两种补给模式、无踪步、最后一次回气移动、击杀跟进、无效操作、移动后反击击杀、满盘丢弃以及存档回放。原有v0.8.1合同测试显式使用旧快照，继续检查旧存档兼容。结果见 `Logs/exhausted-supply-tests-final.xml`。
