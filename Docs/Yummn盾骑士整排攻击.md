# Yummn 盾骑士整排攻击

2026-09-10

只改 Yummn，新对局中盾骑士不再等玩家贴脸才准备攻击。

- 准备阶段按与弓手相同的方向选择方式锁定横向或纵向，同时转动盾面。不在同行列也会尝试锁定。
- 下一次敌方阶段攻击已经锁定的方向，中途不追着玩家转向。攻击后清空预警，再下一阶段重新瞄准。
- 范围是盾骑士前方直到边界的一整条直线，包含玩家身后的格子。墙、冰柱和暗幕阻挡，不被其他敌人阻挡，不造成敌人友伤。
- 仍造成 1 点伤害，保留剑击动画、音效与原有近战防御判定；不是给盾骑士换上弓箭。盾牌正面免伤、侧背受伤规则不变。
- 冻结、震慑、暗影斗篷和出生准备的限制仍保留。
- 预警显示整条攻击路线，危险提示按锁定方向及当前障碍检查。教程同步更新。

Kait 使用原来的规则，不受影响。旧 Yummn 存档保留原规则，重新开始一局启用本改动；规则随存档保存，成绩分开记录。
