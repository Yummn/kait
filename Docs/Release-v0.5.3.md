# v0.5.3 主界面版本

这一版补上游戏入口。人物选了 A 版的紫瞳驻剑造型，背景沿用 B 版的翠绿庭院和斜切构图，右侧保留烟墨色与桃粉色菜单。

## 改了什么

- 打开程序先进入主界面，不再直接开始一局。
- 开始游戏、玩法教程、设置是三个独立按钮，有悬停和按下反馈，支持鼠标和触屏。
- 教程沿用现有八章图解。中途关闭回到主界面，最后一页的“开始游戏”可以直接开局。
- 设置沿用原来的五个开关。主界面调整墙体不会提前启动游戏，进入游戏后按选项生成棋盘。
- 菜单、教程和设置会拦住战斗方向输入，关闭界面的这一帧也不会误走一步。
- 主界面按 1920×1080 设计，在手机安全区内等比显示，不拉伸人物或裁掉按钮。
- 收入上一轮双格共鸣、俯视裂隙分段预警的收尾修正：联动提示也覆盖连杀等待分支。

主界面人物目前是插画中的静态人物；战斗里的 Spine 动画没有更换。卡片特效和胜负特效仍按此前约定暂缓。

## 验证

Windows 构建完成，最终源码的 EditMode 测试 405 项通过、0 失败。运行版检查了初始菜单、按钮射线命中、按下恢复、教程打开和关闭、设置开关、开始游戏、实际移动，以及教程末页开局，并查看了生成的截图。

双格共鸣另跑了普通映射、改道、取消刷新和 12 步游玩四组回归，全部通过。脚本分别是 `Tools/verify_main_menu.ps1` 和 `Tools/verify_linked_cells_b.ps1`。

本次没有连接到 ADB 设备，因此不能把安装包构建成功视为真机启动和性能验证。安卓仍沿用 ARM64 / IL2CPP 和标准 UnityPlayerActivity，保留之前的启动兼容修正。

安卓包构建成功；已检查内部版本号 503、最低 API 26、ARM64 架构、UnityPlayerActivity 启动入口，APK v2 签名验证通过。IL2CPP 元数据中包含本次新增的主界面类。
