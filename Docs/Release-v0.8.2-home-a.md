# v0.8.2：烟墨双境首页

这次把人物选择并进了首页。左边是 Kait，右边是 Yummn，中间保留开始、继续、教程和设置。菜单沿斜线逐行居中，点击人物只切换选择，确定开始后才进游戏。

- 两个人物都有轻微浮动，悬停和选中时放大；裁线不会跟着晃动。
- 继续按钮统一放在开始上方，读取所选人物的存档。没有存档就不显示。
- Kait 和 Yummn 教程都改成三页漫画，核心规则直接看图，其他内容放在“详细说明”。教程不再写死召唤 Boss 的数字。
- 气点区分卡通与极简样式，气槽居中，悬浮面板的裁线偏移统一。
- 同步此前的裂隙刷新延迟、幻影整回合承伤、掌印方向和人物待机调整。

规则版本仍是 0.8.2，保留已有存档兼容方式。本次没有重新设计战斗规则。
