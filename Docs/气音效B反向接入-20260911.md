# 气音效 B 组反向接入

按用户最终选择，B组的收放用途对调，不是把音频倒放。

| 游戏用途 | 获批试听原件 | 正式资源 |
| --- | --- | --- |
| 消耗气 | B_gain_raw.wav（原回气） | Audio/Yummn/SelectedModel/KiSpendB.wav |
| 回气 | B_spend_raw.wav（原放气） | Audio/Yummn/SelectedModel/KiGainB.wav |

来源目录：AudioPreviews/QiNatural-20260911。原件直接复制，保留48kHz双声道PCM，不变速、不调音高。旧Ki.wav保留，由加载映射使用新回气声。

耗气在已接受行动的表现开始时播放一次，按totalKiCost或attackCostTenths判断；不使用行动前后净差，避免同次击杀回气把耗气抵消。免费攻击、免费气竭移动不播放耗气声。回气仍由实际获得资源的Resource事件播放，满气未实际增加时不触发。气竭与恢复高速的Exhaust/Recover提示、其他音效和规则不变。

YummnKiAudioTests覆盖免费行动、移动/技能扣气、高速攻击扣气、旧0.1兼容与两个资源加载。构建和测试最终状态见SHARED_CHANGELOG.md。未生成安卓或上传GitHub。
