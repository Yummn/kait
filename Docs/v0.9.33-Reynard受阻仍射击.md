# v0.9.33 Reynard受阻仍射击

## 规则

- 每次方向输入都执行一次方向射击。
- 可以移动时，Reynard先移动一格，再从新位置朝输入方向发射1伤子弹。
- 被敌人、柱子或地图边界阻挡时，Reynard留在原地，但仍朝输入方向发射子弹。
- 相邻敌人阻挡移动时会成为子弹遇到的第一个目标并受到1点伤害。
- 障碍或边界挡住弹道时仍播放朝该方向发射的表现；魔法飞弹阵、环身狐火等“射击后”效果仍会结算。
- 右盘滑动、补2和敌方阶段不因人物受阻而取消。
