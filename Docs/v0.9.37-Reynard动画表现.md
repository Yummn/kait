# v0.9.37 Reynard 动画表现

本轮统一 Reynard 与其专属敌人的 Spine 动画映射，并让基础法球只在确实存在目标时出现。

## 动画与攻击表现

- 普通方向操作先检查实际弹道：前方没有敌人时不创建法球、不播放攻击，只播放 `walk` 完成移动。
- 弹道上存在敌人时，移动阶段播放 `jump_f`，抵达后播放 `attack`，法球飞向实际命中的敌人格。
- 被阻挡但相邻方向存在敌人时仍会原地播放 `attack` 并命中；无敌人的受阻输入不生成空弹道。
- 直接伤害主动技能播放 `skill`；法术反制、云雾术、石墙术等防御技能播放 `uniqueskill`；传送、控制及其他技能播放 `prepare`。
- Reynard 受击在 `hit_1` / `hit_2` 中随机选择。
- 镜狐人物残影使用 `idle_2` 循环待机。

## 敌人表现

- Reynard 专属敌人移动时复用场上 Spine 角色并循环 `walk`，位置按原先先快后慢曲线移动，血条同步跟随。
- 敌人受击在 `hit_1` / `hit_2` 中随机选择。
- 被群体定身或蛛网控制时循环 `stun`，控制解除后恢复预备攻击或待机。
- 对 Reynard 造成致命伤害的敌人在结算面板出现前循环播放 `win`。素材没有 `win` 的杂兵和术士以 `uniqueskill` 循环作为兼容后备。
