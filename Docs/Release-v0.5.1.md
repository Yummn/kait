# v0.5.1 庭院、卡片与战斗反馈

这次是在 v0.5 被动构筑的基础上整理表现和操作，没有另起一套规则。之前改动比较零散，现在留一个完整归档，方便后面继续换特效，也方便回退。

## 主要变化

- 左侧换成翠绿色庭院，右侧保留简约的 2048 盘。树木、花草拆成独立装饰，补上地面投影和人物接触阴影。
- 被动牌贴在上边缘，主动技能牌贴在下边缘，可以拖动、吸附和展开。主动技能拖到中间使用，冷却信息保持可见；卡片跨过分割线时切换对应画风和图标。
- 整理了命中、推动、击杀、连杀、格挡和刀光的表现，调整特效尺寸与层级，尽量不遮住角色。陆续接入角色受击 B、箭矢命中 A、术士 A、出生薄尘 A、边界急停 A、速度强化 B 和惊惧斩 A。
- 惊惧斩的斩压跟着敌人一起推移，不再沿路径逐格延迟播放；上下急停烟尘改为沿移动反方向拖尾。去掉敌人移动替身上残留的粉色底板。
- 换入已选定的武器、远程、技能、场景、卡片和界面音效，保留角色语音与现有混音逻辑。
- 数字盘合成音效改用 Merge_B，保留原来的随合成点数升调；移动起步仍用拔剑音效。
- 增加翻页教程，以及相关资源、规则和表现检查工具。

冰墓的新画面 A/B 还在选方案，本次没有接入；不要把已有冰墓功能与这次待选美术混为一谈。次级幻影等后续画面替换也没有算作已完成。

## 验证与使用

本轮惊惧斩和烟尘修改的 EditMode 报告为 379 项通过。Windows 诊断覆盖四方向斩压、四方向急停、普通命中和 12 步玩法，10 项通过；这些是阶段验证记录，不代表每一种技能组合都已完整验收。

Windows 下载包包含运行所需目录和文件，解压后启动 `kait.exe`。Unity 工程使用 6000.0.30f1，打开 `Assets/Scenes/Scene.unity` 运行。本次不重新生成 Android，也不把旧 APK 混进 Windows 包。

本次运行包采用 2026-09-05 12:09 完成的 Windows 构建（`Logs/merge-b-build.log`），包含随后选定的合成音效 B。
