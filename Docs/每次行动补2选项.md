# 旧版移动补给选项

设置新增“每次移动都补一枚2（旧版）”，默认关闭，只对下一局Yummn生效。

开启后按旧版的有效方向操作口径补给：高速移动、气竭移动、原地出拳、替代技能动作，以及只有数字盘发生移动的有效操作，都补一枚2。无效操作不补。击杀和气竭移动不额外叠加，单次操作最多请求一枚2；没有空位时丢弃，不欠账。无踪步不取消这一固定补给，也不再作为此模式的新候选牌。

它与“原地出拳不补新2模式”互斥：开启其中一个会自动关闭另一个。两个都关闭时，回到当前默认的“击杀补2＋气竭实际移动补2”。“从8开始出怪”独立设置，可以搭配任意补给方式。

这次只切换补给方式，不恢复旧版的敌方行动时序，也不恢复锁盘重置。当前的击杀／气竭推进一次敌方阶段、锁盘失败、先结算战斗再补给均保持不变。Boss获胜或人物死亡时不追加补给。

补给模式随每局快照存档，回放使用原模式，成绩单独分组。旧存档与默认设置不变。设置面板重新排布八个选项，教程随本局补给方式显示相应说明。

此次只同步Windows程序，不自动重新打包安卓。

Windows程序已重新编译到 `Build/kait.exe`。实际运行检查了八个设置项的排布、新开关互斥及当前局快照不变，未发现文字越框或QA错误。[设置面板截图](../Logs/every-action.png.every-action-settings.png)。测试结束后已恢复用户原存档及设置，删除本次测试新增的临时偏好项。
