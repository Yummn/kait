# 弓箭与法术音效接入

本轮采用试听选定的四条 ElevenLabs 音效。

| 行为 | 文件 | 触发位置 |
| --- | --- | --- |
| 箭矢飞行 | ArrowFlight_A2 | 敌方弓箭释放阶段 |
| 箭矢命中 | ArrowImpact_A | 箭矢命中结算 |
| 法术释放 | MagicCast_B2 | 术士释放法术时 |
| 法术命中 | MagicImpact_B2 | 法术攻击结算时 |

本次只替换音频引用，不更改攻击逻辑、时序或播放倍率。裂隙生成使用的 MagicImpact_01 保留，法术蓄力、角色语音、近战和卡片音效不变。原始音效资源也保留，方便回退。

四份 WAV 从试听目录直接复制，保留试听时的裁剪，不新增淡出、增益、归一化或峰值处理。Unity 使用 48 kHz、立体声、PCM、DecompressOnLoad，关闭导入归一化。游戏沿用原有通道混音音量及小范围随机音高，游戏内听感会受混音影响。
