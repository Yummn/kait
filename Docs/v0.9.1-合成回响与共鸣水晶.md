# v0.9.1 合成联动调整

法术回响（本次需求中称“法力回响”）保留原卡牌ID和卡图。每次真实合成都会在同一位置额外结算一次完整合成事件。例如2+2产生4，仍只留下一个4，但合成触发结算两次，包括法力珍珠、守卫刻文、魔法飞弹、共鸣水晶、异次元袋、丰饶之壶以及原有奖励/裂隙流程。回响事件不能再次复制自己，各技能原有次数限制和裂隙占格规则继续适用。

共鸣水晶收到一次合成事件后，根据结果数字寻找另外两个同值数字；不使用本次结果所在格。例如2+2产生4后，若盘上还有另外两个4，自动把它们合成8。不限相邻、不限是否本回合产生。候选超过一对时，按滑动前方优先、同行按稳定坐标排序，只合成一对。找不到即消费掉本次触发，不留到以后。

水晶产生的真实合成继续触发合成技能，包括回响和水晶自身。每次水晶合成都减少一枚棋子，因此连锁会自然结束。回响可让水晶额外尝试一对，但不凭空复制数字。系统合成沿用跨格移动动画；原位回响沿用现有回响特效。

应用版本0.9.1，Android版本码901（本次未生成APK）；规则/牌池版本0.9.1-merge-echo，新Yummn存档使用Kait.Run.Yummn.0.9.1。旧存档原样保留，新规则需新开局，避免按新规则重演旧录像。
