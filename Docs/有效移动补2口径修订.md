# 有效移动至少一格才补新2

2026-09-10。本次只修改 Yummn 设置中原“原地出拳不补新2模式”，不改变击杀补给模式、每次有效行动补给模式或 Kait。

## 统一口径

一次有效行动中，Yummn 本人实际移动至少一格，才请求补一枚新2。一次移动多格也只补一枚，击杀不额外叠加。

| 行为 | 此模式是否补2 |
| --- | --- |
| 高速滑行、气竭走一格 | 是 |
| 先移动再出拳 | 是 |
| 原地出拳但未移动 | 否 |
| 击杀后进入敌人原格 | 是 |
| 推掌只推动敌人 | 否 |
| 推掌后追身步进入敌人原格 | 是 |
| 暗影步传送到另一格 | 是 |
| 原地水鞭、吐息、冰柱、暗幕 | 否，即使原地技能击杀了敌人 |
| 人物抵住边界，只移动／合并副盘 | 否 |
| 无效输入、准备或取消技能 | 否 |

无踪步仍保留原有效果：高速状态的未攻击移动可以抑制补2；气竭移动补给不受它抑制。副盘没有空格时只记录本次补给丢弃，不保留欠账。补给时点、敌方阶段、气恢复不变。

判定读取本次结算中的玩家移动事件，不依据“是不是出拳”、敌人移动或副盘动画，也不只比较出拳前的路程。避免漏掉击杀跟进、追身步及传送。

## 设置、教程与存档

- 开关改名为“有效移动至少一格才补新2”。
- 另一旧版选项改用准确名称“每次有效行动补一枚2（旧版）”，它仍然包括原地出拳，规则没有改变。
- 设置说明和对应模式教程明确跟进、传送算移动，原地施法及只动副盘不算。
- 开关沿用原偏好值，新开局采用新判定。旧存档保留原判定，避免回放出不同棋盘；旧局教程按自己的规则显示。
- 新规则快照记录 actualMoveSupply，计分规则键区分 ActualMove。其他模式的计分键不因该字段改变。
