# 白金刀光接入

2026-09-04

普通挥剑使用细弧图集，击杀及连杀使用加强图集。替换原有剑尖轨迹条，不改普通命中、击杀碎裂、格挡与推动反馈，不改音效及游戏规则。

刀光通过当前 Spine 攻击轨道计时，播放 0.28 秒；亮部位置对齐 weaponMainF 附件的剑尖采样点。动画被移动或技能替换时结束，不占用输入锁。这是随剑尖定位的序列帧，不是按整条剑刃顶点生成的曲面。

第一轮运行截图发现：击杀动画内部的角色位移使以格子中心定位的刀光偏到脸旁。已改用各帧亮部中心定位，并将普通/击杀画布上限缩到 180/190 UI 单位。
