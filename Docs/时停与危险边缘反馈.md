# 时停与危险边缘反馈

连杀停留在转向选择状态 1.2 秒后，左下角浮现小时钟，屏幕四周在接下来 1.8 秒内逐渐染灰。继续移动后快速淡出，不调整游戏时间，也不延长动画或锁住操作。

Kait 当前所在位置受到已锁定敌人攻击或下一次结算的裂隙威胁时，四周显示低强度红色呼吸边缘。中心保持透明。红色优先于灰色，两者同时出现时保留时钟。

预警只说明当前位置的危险，不预测玩家接下来会选择哪个方向。读取状态不会消耗防御次数；已考虑无敌、墓地防护、冻结、死亡单位、远程瞄准阶段、箭矢阻挡，以及咒术护甲、幽魂、移位斗篷、秘法锁和书签转移。复杂敌人友伤导致的后续局面变化仍以实际结算为准。

打开教程、设置或主菜单时隐藏，结局后隐藏。特效不接收鼠标或触摸事件。使用 UI 网格直接绘制，无需额外纹理，边缘按分辨率缩放。

预览参数：`-kaitAtmospherePreview 1 -kaitScreenshot <路径>`，输出无特效、时停、危险及叠加四种截图。
