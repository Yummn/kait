# 卡片双画风图标

每张卡片保留一个点击、选择和拖动主体。图标是不可点击的视觉子对象，使用和卡面相同的全局裁切线：左侧画具象插画，右侧显示文字或符号。卡片跨线时，两种图案在同一图标区内分别显示，不是整张卡到达某个位置后突然切换。

插画保留粗描边和大色块，已去掉深靛底板，改用透明 PNG。主动技能使用银蓝卡框，被动使用金色卡框。简约侧的符号有独立圆角矩形外框：主动76×58、被动96×64，约1.5像素细边；旧的被动大装饰框从卡面中移除，外层卡框保留。

## 编辑位置

独立透明插画：`Assets/Resources/KaitVisuals/CardLogos/Transparent/`。文件名和技能、被动枚举一一对应，替换同名图片即可更换卡通图案。上一级目录的原始带底图保留，仅在透明图缺失时回退使用。

空白被动卡框：`Assets/Resources/KaitVisuals/EmeraldCourtyard/PassiveCardBlankHD.png`、`PassiveCardFlatCompact.png`。旧版 `PassiveCardBlankFlat.png` 保留。新简约外框由 `KaitCardLogo` 使用现有双画风 UI 绘制，不画死在卡面里，跨分界线时连续裁切。

简约符号：主动技能在 `KaitSkillCard.Sigil`，被动在 `KaitCardLogo.PassiveSymbol`。

图标布局：`KaitCardLogo.Create` 调用处。主动图标68×68，被动92×92，均在上半部；保持半张卡吸附时的识别性。图片按512像素上限导入，不使用有损纹理压缩。

原画由内置 image_gen 生成，没有下载第三方图标。完整提示词、原始输出路径和项目保存路径见 `card-logo-prompts-0904.json`。透明版沿用本地抠图方式，处理脚本为 `Tools/extract_card_logos.py`，原图不覆盖；对深色羽毛和衣物采用封闭轮廓保护，避免误删与底色接近的内部颜色。预览及透明像素统计位于 `VFXScreenshots/card-polish/`。

主动卡的吸附中心由屏幕底边上移24像素（1920×1080参考尺寸），冷却状态行完整露出，并留出15像素下边距。悬停展开、拖动打出、冷却期间拒绝施放等规则不变。

预览交互：鼠标悬停在已拥有技能卡上时保持完整展开；移开鼠标后保留3秒，随后收回。点击或触摸卡片展开并刷新3秒保留时间。点击卡片外部（包括另一张卡片或其他面板）会提前收回，使用最上层UI命中对象判断，不吞掉原点击。未选择的候选卡不会被自动收起；正在拖动的卡不受其他触点干扰。收回只是关闭预览，不取消技能选目标。按住卡片准备拖动时冻结自动位移，避免抓取点漂移。
