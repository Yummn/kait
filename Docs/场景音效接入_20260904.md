# 场景音效接入

本次接入用户选定的四条 ElevenLabs 音效。

| 行为 | 文件 |
| --- | --- |
| 裂隙开启预警 | RiftOpen_B2 |
| 敌人出生落地 | SpawnLanding_A |
| Kait 撞边急停 | WallStop_A2 |
| 技能就绪提示 | SkillReady_A2 |

落地和急停不再共用 Push_02，分别使用独立音频引用。现有触发时机、混音通道、播放音量倍率和随机音高范围保持不变，不增加额外播放次数。已经选定的近战、远程、卡片音效和所有角色语音保持不变。

WAV 直接复制自试听目录，逐文件 SHA256 相同，没有额外裁剪、淡出、增益、归一化或峰值处理。Unity 导入使用 PCM、48 kHz、立体声、DecompressOnLoad，关闭导入归一化。游戏原有混音仍会影响最终听感。

资源目录：Assets/Resources/Audio/World/SelectedModel。
改动前备份：Backups/world-audio-before-20260904/GameAudio.cs。
旧音频资源未删除，便于回退。本轮只更新 Windows，不生成 APK。
