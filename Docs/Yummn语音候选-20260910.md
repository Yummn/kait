## 本次范围

只筛选与制作试听，不接入游戏，不改正式音效或原语音文件，不打包、不上传。共享入口：[SHARED_CHANGELOG.md](C:/Users/yummn/Downloads/kait/Docs/SHARED_CHANGELOG.md)。

使用本地已解压的两包“伊甸园 语音（日）”。先排除已用于 Kait 和敌人的 Gloria、April、Olivia、Monica、Bridget、Aloe、Ursula。本轮从其余声库中选取六套、每套十二条，共72条做首轮初筛；不是遍听了所有声库。

筛选依据为文件用途、实际时长及战斗片段配套。使用本地 Whisper tiny 做辅助识别，但短促喊声存在明显错字和重复幻觉，因此不提供未经核实的中文翻译，也不声称已经完成声线、情绪或角色设定匹配的听辨。最终适合与否以用户试听为准。

六个连续试听文件均按 **普通攻击 N2 → 普通攻击 N3 → 技能 H1 → 开场 Go1** 排列，中间留0.7秒空白。只拼接预览、转换为48kHz双声道PCM，不调音高、不变速、不做响度归一化；原文件不动，选定后再规划统一响度和播放频率。
