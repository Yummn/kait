# v0.6.1 牌池构筑与拖拽选牌

这次把9月6日至7日的改动收成一个完整版本。主要是在原有双盘玩法上补齐牌池，再把选牌操作和画面整理了一遍。

## 这版改了什么

- 接入14张主动、24张被动。狂野魔法保留定义但默认关闭，不进入正式奖励池。
- 16＋16合成32获得混合三选一，主动、被动都有候选。每组最多一张金牌，连续三组无金后下一组保底。
- 主动、被动各有3个槽位。新牌拖到空槽装备，拖到旧牌替换；拖错会归位，不消耗奖励。拟像术分两次拖动，先复制再装备。
- 新牌等到下一次有效全局输入才生效，原牌规则在此之前保留。无效移动不提前激活。
- 首次合成256召来本局目标Boss，击败这名Boss获胜。
- 换入新牌图和对应技能反馈。主动与被动靠卡面外形区分，稀有度靠白银、蓝、金区分，不再叠加剑盾和星级标记。
- 教程更新为10页，补了奖励、拖拽替换和拟像术的小漫画。
- 选牌控制栏可以从左侧牌数区域拖动；过斜线时切换画风，按钮仍共用一套操作与按下反馈。
- 树冠轻微浮动，花草错峰摆动；树干、地砖和棋盘保持稳定，阴影继续跟随。

## 程序与检查

Windows包完整解压后运行kait.exe，不要只拷走exe。Android包支持Android 8.0以上ARM64设备。

最近一次EditMode报告485项通过，Windows中检查了拖拽替换、两步复制、控制栏左右裁切、教程排版和环境摆动。Android于9月7日重新构建，签名和启动入口检查通过；当时没有连接ADB设备，尚未真机验证本次安装包。

这里归档的是最终保存下来的v0.6.1，不把几次覆盖构建伪装成多个可回退版本。更早的小步改动，有保留的备份另外收进历史资料包。
