# 气槽居中与悬浮裁线右移

按本次要求，悬浮 UI 的统一裁线偏移由 -12 改为 +28（1920×1080 设计像素），相对背景向右移动，斜率保持不变。初版 +12 实机最右气点擦线，统一加至 +28，非单个面板偏移。各菜单及子元素仍使用同一个裁线坐标系，背景和新人物选择界面不变。

气点颜色、卡通 B 与极简圆点、空槽、小数填充及气竭配色不变；不改任何回气、耗气和敌方行动规则。
