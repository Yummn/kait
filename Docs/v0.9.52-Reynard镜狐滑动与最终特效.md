# v0.9.52 Reynard 镜狐滑动与最终特效

## 本次修改

- 按审批结果接入燃尾新星 C「双尾星坠」和群体定身术 B「狐耳封笼」。两套效果都使用透明 4×2、八帧序列，并在技能实际生效的位置播放。
- 新增独立的循环法印表现：八帧月蓝呼吸法印，错开每个格子的播放相位，避免多个法印整齐闪动。
- 镜狐不再留在数字原位。威胁盘滑动时会先识别真正携带镜狐的源数字，再让残影与该数字使用同一段 `EaseOutCubic` 路径同步移动；吞入的目标数字不会错误继承镜狐。
- Reynard 专属弓手缩放调整为 1.16，重甲调整为 1.18；人物定位改按身体范围的二维视觉中心计算，长弓、盾牌和外围特效不再把人物挤离格子中心。
- 主棋盘草边框改为完全不透明，遮住地砖外围的硬边和透底，不改变格子、碰撞或点击范围。
