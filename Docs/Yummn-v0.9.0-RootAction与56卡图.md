日期：2026-09-13。基于本地 v0.8.3 工作树修改，没有退回文档引用的旧 GitHub 基线。

## 本次改动

一次方向/等待/主动技能操作作为一笔 RootAction：人物动作与连锁 → 副盘基础滑动/真实合成/摆锤 → 补给及归档连锁 → 至多一次出生窗口与敌方阶段 → 返还数字、回气和状态切换 → 锁盘与输入稳定点。

- 操作起手时固定高速/气竭资格，击杀回气即时到账，气格挡不再中途切换全局状态。
- 进入四邻触发伺机而动拳击，高速起手限定；离开四邻在位移提交后触发踢击，含人物移动与传送，气竭也有效。各技能每敌人每操作一次。
- 气竭普通攻击为免费1伤踢击，不触发疾风、推掌、火蛇、震慑等拳掌效果。拳掌攻击保留完整连击与追击链。
- 追身步到敌人最终落点前一格，不能穿过阻挡；整段一个起点残影。
- 普通滑动按实际提交格数扣气，预览格数不再截断被连锁打开的路线；反应稳定后继续原输入方向。固定1气移动仍整段只付一次。
- 范围伤害先固定直接目标，后处理碎冰及反伤；同一敌人攻击命中多个残影/诱饵最多回1气。误导术改变未锁定敌人的目标，不跳过正常瞄准。
- 新裂隙可以在本操作唯一出生窗口兑现；敌方行动中产生的裂隙不再开第二窗口。命令术只执行指定敌人的正常动作，不独自推进阶段或扣残影寿命。
- 真实合成记录来源与编号，先原始合成攻击再复制旧攻击；异次元袋在滑动批次后处理。共鸣校验数字身份，丰饶之壶在尾部返还，不重入合成。
- 阶段切换、选牌、技能点选或结束时清除长按旧输入。主盘播放结束后才开始副盘播放。
