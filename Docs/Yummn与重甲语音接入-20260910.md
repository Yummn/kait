# Yummn 与重甲语音调整

用户选定 Yummn 使用 Bridget，并授权给重甲敌人更换另一套配音。本轮重甲改为 Coonya；Kait 的 Gloria 和其他敌人声库不变。

## 映射

Yummn 所有语音均来自 Bridget：普通攻击 N2–N5；击杀 N1；同一行动第二次击杀 N6，后续使用普通攻击池；技能实际执行时 H1；受击 Hit1/3/5，重伤 Hit6；开场 Go1、胜利 Win1、失败 Fail1、死亡 Die1。H2/C2 也按同一声库映射保留给现有大技能/终极语音接口。技能仅准备/取消时不播技能语音。

重甲 Coonya：普通攻击 N2/3/4，低频攻击 N1/5，准备攻击 H2，登场 Go1；受击 Hit1/2，推动 Hit3，重伤 Hit4，死亡 Die1，击败主角 C1。仍使用原重甲独立语音通道和新语音压低旧敌人语音的逻辑。

保留所有已经选定的非人声音效。Yummn 击杀只调用新增语音接口，不借用 Kait 的刀剑击杀音效。取消原来对 Yummn 主角语音的直接禁用，按角色解析 Bridget；资源缺失时保持静音，不回退播放 Gloria。敌人攻击反馈的通用受击语音在 Yummn 下由有序 Hit 事件负责，避免重复播放。

## 文件

- Assets/Scripts/GameAudio.cs：角色语音解析、重甲声库、Yummn 击杀语音。
- Assets/Scripts/KaitGame.Yummn.cs：真实行动的攻击、击杀、技能、受击触发。
- Assets/Scripts/KaitGame.cs：避免 Yummn 通用敌人攻击反馈再次播受击。
- Assets/Resources/Audio/Voice/Yummn/Bridget：20个 WAV。
- Assets/Resources/Audio/Voice/Enemies/Coonya：18个 WAV。
- Assets/Tests/Editor/YummnVoiceBankTests.cs：31项资源与角色分流测试。

原素材来自本地伊甸园语音1已解压目录，未改。只对新增工程副本运行 Tools/normalize_voice.py：沿用 -20 dBFS 活跃语音电平与 -1 dBFS 峰值上限；38条均达到 -20 dBFS，不变调、不变速。旧重甲 Bridget 资源保留，现有重甲加载已不再引用，便于回滚。
