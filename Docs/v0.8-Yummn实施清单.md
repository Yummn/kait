## 规则与文件分工

YummnRun 保存气、阶段、冰柱、暗幕、掌印、准备列表和统计。KaitYummnRules 是兼容入口，只有有效动作通过候选构筑校验后才提交。YummnCardEffects 和 YummnEnemyAI 不调用 Kait 的 FinishTurn。枚举仅用作旧 UI 适配，卡池使用 yummn.M01 等稳定字符串 ID；既有 Kait ID 不重排。

普通拳不推人。疾风连击为同目标最多三拳，主拳击杀进入目标原格；火蛇、碎冰、掌印和反击等附加击杀不把人物拉过去。控制分别记录冻结和震慑，不用一个计数器混淆来源。

高速输入耗基础1气，气竭输入基础0气；已准备技能另外花气。最后1气击杀后先回气再判阶段；气竭过程中回满仍完成本次敌人阶段，下次输入才高速。无效输入、气不足和非法目标不会扣气、推进副盘或激活新装备。

三宗派无需选职业，可以跨派混搭。正式池30张，实验牌与旧“双行动”分支未放入 Yummn 池。依赖牌只认实际拥有的前置，不能借同一组另一张候选满足条件。旧候选不悄悄重抽，替换前置有确认和取消。
