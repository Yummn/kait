# v0.9.22 Kait 人物卡图统一

## 目标

逐张检查 Kait 的47张正式卡图。凡画面中直接出现 Kait Q版人物的卡图，统一使用同一角色设定；纯道具、法术图案、敌方剪影和环境符号不为统一人物而强行加入角色。

## 统一角色设定

- 黑紫色齐肩头发与猫耳。
- 琥珀金色眼睛。
- 黑棕色无袖咒剑士护甲、紫色布片、金色扣带与饰边、白色毛绒点缀。
- 巨型暗色咒剑，剑身带紫色诅咒纹与青紫能量。
- 卡图继续采用与 Yummn ApprovedA 一致的Q版大色块平涂、深紫粗轮廓和简化赛璐璐阴影。
- 透明背景，不绘制卡框、名称或稀有度；由游戏界面统一叠加。
