# 选牌界面信息精简

2026-09-07

选牌时原有的顶部说明、中央说明和卡底说明重复表达同一套拖拽操作，覆盖了较多战场。保留牌名、效果和必要状态。后续按反馈取消卡面剑盾与稀有度数量标记，直接由卡面外形和颜色表达。

- 卡面外形区分主动与被动，白银、蓝、金区分稀有度；删除剑盾、数量标记及其底条。
- 取消下方剑盾方向图示，无提示时整条提示背景隐藏。主动卡保留时钟与数字显示基础冷却。
- 空槽显示加号，已有卡槽显示替换符号，有效悬停显示对勾。槽位名称保留，以免换错。
- 去掉卡底常驻拖拽说明，取消中央大段文字。错误、替换目标及拟像术两步操作只显示短提示。
- 顶部用卡牌图标与数量显示待选奖励，按钮用图标加两个字；触屏点击区域仍为144×60。
- 不改变牌池、拖拽判定、冷却和激活时机。教程补充图标含义。

线条图标为代码绘制，不需要额外图集，也不依赖 Android 的 emoji 字体。
