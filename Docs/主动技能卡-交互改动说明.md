# 主动技能卡

移除中间技能栏和原来的成长按钮面板。被动仍贴在上边缘，主动技能改为银蓝卡片，贴在下边缘露出一半。两个棋盘不移动，WASD 和重新开始面板略微下移，为中间出牌区留出空间。

## 操作

- 点按或鼠标移上卡片：展开查看，不直接施放。
- 拖动已获得的技能到屏幕中间：出现出牌提示，进入区域后显示“松手打出”。松手立即执行技能逻辑，卡片短暂缩小后返回下边缘。
- 在其他位置松手：不消耗技能，按新的横向位置吸附到底部，并与其他卡片错开。
- 冷却中仍能拖动整理，但不能施放。卡面持续显示冷却回合数。
- 冰墓和次级幻影：先拖到中间打出，再点选敌人。中间保留提示和取消按钮；选好合法目标后才进入冷却。
- 惊惧斩：打出后输入方向发动。踏影：击杀后满足原有条件时可打出。
- 获得技能时，两张候选卡从下方浮出，点选一张加入底部。选择不暂停游戏；候选卡避开中间方向按钮。
- 技能动画不阻塞卡片交互；连杀途中仍可使用可用技能。卡片拖动不会变成滑动移动指令。

## 外观

主动技能使用银蓝框和专属符号：疾步之靴 `+1`、猫之迅捷 `×2`、惊惧斩 `斩`、冰墓 `冰`、次级幻影 `幻`、踏影 `跃`。与上方金色羽叶被动卡区分。卡片名称、效果、冷却均为实时 UI 文本，不写死在图片中。

双画风继续使用一个卡片主体和一套输入逻辑，只在分界线两侧切换材质与字色。

素材位于 `Assets/Resources/KaitVisuals/EmeraldCourtyard/SkillCardHD.png` 和 `SkillCardFlat.png`。本次用内置 imagegen 生成两版卡框；完整提示词保存在 `Docs/Skill-cards-prompts.json`。

代码：`KaitSkillCard.cs` 负责卡片手势，`KaitSkillDeck.cs` 负责磁吸、候选卡与出牌区，`KaitGame.cs` 接入原有技能逻辑。核心技能效果和冷却规则没有调整。
