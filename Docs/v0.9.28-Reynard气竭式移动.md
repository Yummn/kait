# v0.9.28 Reynard 气竭式移动

Reynard 的普通移动不再维护独立的近似动画逻辑，改为直接复用 Yummn 气竭状态的移动协程。

## 表现

- 使用相同的三次缓出曲线，起步快、到位慢。
- 使用相同的按距离计算时长；单格移动约 0.165 秒。
- 使用 `walk` 循环，不生成速度残影。
- 人物移动与威胁盘动画同时开始，不再先移动人物、随后再移动副盘。
- 演出期间允许记录一个后续方向，当前回合演出结束后立即衔接；奖励出现、终局或等待时会清空。
- 单帧动画步进上限为 1/30 秒，短暂掉帧也不会直接跳过整格。

## 验证

- `Logs/reynard-movement-0928.xml`：Reynard 专项 33/33 通过，主控 Spine 含 `walk` 动画。
- `Logs/reynard-runtime.log`：`REYNARD_MOVE_INTERMEDIATE 0.4918689`、`REYNARD_QA_COMPLETE`，运行时确认移动存在中间帧，且实际播放 `walk`、无移动残影。
- `Logs/reynard-movement-0928-windows.log`：Windows 构建成功退出。
