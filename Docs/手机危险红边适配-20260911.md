# 手机危险红边适配

红边原本就是 Canvas 的全拉伸子对象，不是固定在棋盘上。问题在于 DangerC 四周有透明留白，九宫格角部采用固定 UI 尺寸；铺满的是图片矩形，而非可见图案，宽高比变化后内缩感仍然存在。

保留已选 C 素材及九宫格，不拉伸角部图案。角部改为屏幕短边的 16.5%，向屏幕外延伸角部的 15% 来补偿素材约 6% 的透明边距。尺寸改变、切换分辨率及播放逐帧时均重新适配。不使用安全区作为红边边界，不挡点击，不更改触发规则、时钟或灰色渐变。

新增测试覆盖 16:9、20:9、19.5:9、平板 16:10、竖屏以及运行时尺寸变化。此为布局与资源检查，不等同 Android 真机截图验收。素材各帧的自然破碎轮廓保留，并非要求每一像素都填满屏幕边线。
