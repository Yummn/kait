# 主动技能拖放与目标分类

点击已装备的主动卡只展开详情。将卡拖到中央释放区并松手后，才进入选目标状态。

| 技能 | 确认方式 |
| --- | --- |
| 疾步如风·收势、冬之吐息、暗影步、影遁术、空震掌、空冥身 | 点击人物四周的方向按钮 |
| 疗伤冥想 | 点击 Yummn 自身 |
| 塑造流水、黑暗术、次级幻影 | 点击棋盘上的空目标格，不限相邻格 |

选目标期间，方向输入不移动人物。选中无效目标或气不足时提示释放失败，退出选目标，不扣气、不推进回合。取消后需要重新拖出卡牌。
