# 裂隙同操作出怪修复

合成在玩家行动前创建裂隙；气竭行动尾部又执行刷怪检查。原检查未区分本次新建和之前存在的裂隙，导致新裂隙同次操作直接变成敌人。

当前v0.8.2刷怪检查跳过createdTurn大于等于当前turn的裂隙。操作完成后turn递增，后续操作触发正常刷怪检查时才允许出怪。旧裂隙照常检查；占格仍等待，不增加伤害、不改敌方行动触发条件。Kait和旧v0.8/v0.8.1回放规则不改。

代码：Assets/Scripts/YummnEnemyAI.cs；v0.8.2教程同步说明新裂隙本次不出怪。

回归用例覆盖：气竭合成、开启有效移动推进敌方的高速合成、下一次等待出怪、新旧裂隙共存、同操作重复检查不能绕过预警。
