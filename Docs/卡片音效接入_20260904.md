# 卡片音效接入

使用用户从第一轮卡片试听中选定的四条音效：

| 行为 | 音效 | 触发位置 |
| --- | --- | --- |
| 拿起卡片 | CardPickUp_A | 主动／被动卡片开始拖动，只响一次 |
| 磁吸归位 | CardSnap_A | 手动释放的已拥有卡片到达边缘卡槽时 |
| 主动卡打出 | CardPlay_A | 中央释放被接受后；需要选目标的技能在进入选目标阶段播放 |
| 被动确认 | PassiveConfirm_B | 规则确认成功获得被动后，替换旧通用点击音 |

自动排版、窗口尺寸变化、悬停展开、候选卡片自由摆放不会触发归位声。无效释放不会播放打出声，回到卡槽时仍可播放归位声。成功打出的卡片回收不额外播放归位声。再次拿起、隐藏或结束游戏会取消尚未播放的归位声。

音效来源是 ElevenLabs Sound Effects；文件直接复制自 cards_round1 试听目录，与用户选定 WAV 的文件哈希一致。保持原有裁剪，不新增淡出、增益、归一化或压缩。Unity 采用 PCM、48 kHz、立体声，关闭导入归一化。独立卡片通道音量 0.72，单次播放倍率 1，固定原音高。背景音乐、武器、角色语音和技能本身的效果声均保留。

资源在 Assets/Resources/Audio/UI/SelectedCards。修改前的四份脚本备份在 Backups/card-audio-before-20260904。本次只更新 Windows，不编译安卓。
