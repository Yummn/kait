# v0.9.0 · Yummn时序重构与56张新卡图

这次主要整理了 Yummn 的整套结算顺序，并把之前选定的 A 版技能插画接进游戏。也一并收录了上次上传后完成的56张牌池和失败重开清理修复。

## 主要变化

- 一次操作先处理人物动作与连锁，再处理数字盘合成、补给和敌方行动，最后统一处理回气、状态切换与锁盘。每次操作最多打开一次出生窗口、推进一次敌方阶段。
- 拳击和踢击分开：伺机而动在进入攻击范围时触发拳击；借机攻击在离开范围、位置提交后触发踢击。气竭普通攻击也使用踢击，不再带出拳掌技能效果。
- 推动后的追身以敌人最终落点为准。连锁打开路线后，人物继续原来的输入方向，移动费用按实际走过的格数计算。
- 整理碎冰、残影反伤、命令术、误导术，以及数字盘合成、共鸣、摆锤和返还数字的先后顺序。
- Yummn牌池为56张，15张主动、41张被动；11张普通、33张非凡、12张稀有。六个装备槽可混装。
- 接入56张选定的卡通插画，去掉图内固定卡框和底色。卡框及稀有度颜色独立显示，右侧仍用极简图标。
- 修复失败后重新开局时，旧敌人、裂隙与部分特效可能残留的问题。

完整技能表和实现记录见 [全局时序与56卡图](https://github.com/Yummn/kait/blob/v0.9.0/Docs/Yummn-v0.9.0-RootAction与56卡图.md)。

## 安装与存档

附件 `kait-v0.9.0.apk` 为 ARM64 安卓安装包，要求 Android 8.0 及以上，横屏运行。安装包约253 MB，版本号900，签名与0.8.3一致，可以覆盖安装。

**请新开一局 Yummn。** 新版使用独立存档键，旧存档保留，不混用新旧规则；Kait存档不变。不要为了更新先卸载旧版，以免删除手机本地数据。

源码对应 Unity `6000.0.30f1`，启动场景为 `Assets/Scenes/Scene.unity`。本次附件只提供安卓包，旧Release中的Windows包不代表0.9.0；本地Windows版已同步，仓库可自行构建。
