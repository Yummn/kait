# 翠绿庭院 A3

本次沿用选定的翠绿色调，替换左侧庭院、地砖、障碍石块、裂隙以及高清界面素材。右侧 2048 简约配色、双盘位置、角色动画、技能和被动规则没有调整。

## 素材与层级

素材目录：`Assets/Resources/KaitVisuals/EmeraldCourtyard/`。

| 文件 | 用途 |
| --- | --- |
| Garden.png | 翠绿草地和边缘树木、花草 |
| Floor.png | 浅米白地砖，铺满单元格，不留草缝 |
| Pillar.png | 俯视深色石块，独立覆盖在地砖上 |
| CanopyMask.png | 共用树影遮盖范围 |
| Rift.png | 裂隙形状，贴在原地砖上，不替换地砖底色 |
| Panel.png / Button.png | 左侧米白框体、深蓝按钮 |
| PassiveCardHD.png | 左侧高清被动卡片 |
| PassiveCardFlat.png | 右侧简约卡片，沿用旧版文件 |

树影和裂隙文件是黑白覆盖图，白色表示空白，不能直接作为普通不透明图片显示。`UIGroundMask.shader` 将其转成带透明度的着色层。草地、地砖和石块通过 `KaitGroundDecal` 共用草地坐标，所以树影不会在每一格重新开始。角色脚下另有轻量接触影，不增加角色裁剪遮罩，残影不生成接触影。

卡片仍共用同一个拖动、吸附和输入主体，裁切线只决定显示哪一种外观。框体和按钮保留九宫格缩放及原有按下反馈。
