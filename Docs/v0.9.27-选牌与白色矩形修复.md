# v0.9.27 选牌与白色矩形修复

## 问题与原因

- 奖励已进入队列但战斗演出尚未结束时，卡盘会提前显示。卡牌此时不可操作，却会挡住战场输入，看起来像选牌卡死。
- 只有 Yummn 拖牌时会屏蔽方向输入，Kait 与 Reynard 拖牌仍可能同时触发移动。
- 未装备卡的隐藏控件也会刷新 Reynard 法术环级文本；定义为空时产生异常，中断选牌刷新。
- 旧存档中的牌若在新版改过类型或移出定义，替换槽位时会访问空定义并中断。
- Reynard 持续法术、镜狐标记和逐帧法术图创建 `Image` 后再加载素材；贴图缺失时 Unity 会显示默认白色矩形。

## 修改

- 奖励仍正常排队，但只在当前连斩、结算和演出结束后显示。
- 所有角色的选牌点击、拖动及替换确认都独占输入；失焦、暂停或关闭界面会清理拖动状态并恢复原卡栏。
- 隐藏主动牌和旧存档空定义增加空值保护，旧槽位仍可正常替换。
- 同类型替换保留原槽位顺序。
- 所有动态 Reynard 图像改为先确认贴图存在再创建；卡牌图缺失时显示透明，不再回退成默认白块。
