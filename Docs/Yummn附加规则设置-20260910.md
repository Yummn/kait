# Yummn 附加规则设置

更正：用户要求高速攻击消耗在 **0气 / 1气** 之间切换，不是0.1气。气竭不扣；气不足仍出拳。有效移动推进敌方是额外条件，原地击杀和气竭原地攻击仍推进。

## 选项

- 高速攻击耗气：关闭为0气，开启为1气，默认0气。普通拳每拳扣一次，疾风连击每个实际出拳扣一次；水鞭/吐息每次施放扣一次，不因多目标重复扣。附带伤害、反击不另扣。气竭和本次已触底后的后续拳不收费，仍照常出拳；技能原有牌面费用不变。
- 有效移动额外推进敌方：默认关闭。人物移动至少一格，包括击杀跟进、推动跟进和传送；仅敌人或副盘移动不算。与击杀、气竭、可选攻击条件做 OR 合并，一个行动最多一次敌方阶段。
- 补给切换：每击杀 / 旧版动作（原地拳不补） / 每次方向操作 / 每次有效移动。最后两种每行动最多一枚，不额外叠加击杀补给。方向模式包括撞墙；未通过验证的技能不提交、不补。有效移动包括跟进和传送。

仅出现在 Yummn 设置中，修改仅下局生效。旧存档缺少新字段时默认为关闭，旧补给枚举值不变；新规则纳入计分键和回放快照。无踪步不抑制新增的“每次”实验补给模式。

旧版误做的0.1气回放仍按原规则读取，避免损坏历史存档；新设置不再提供0.1气。曾开启旧开关的用户，下局默认转为1气，可以关闭为0气；本局快照不改。新规则使用独立计分键。无新增特效、音效审批或接入，不构建Android、不上传GitHub。

测试与Windows交付证据见共享修改清单 RULE-20260910-OPTIONS。
