# 拖拽选牌与教程更新

## 操作

奖励卡现在用拖动来装备，不再通过小按钮确认。点卡只查看，并显示可用槽位；拿起后拖到上方被动槽或下方主动槽，槽位变绿，松手确认。

- 空槽：装备新牌。尚有空槽时也可以直接替换已有牌。
- 旧牌槽：替换这一张，其他槽位不变。
- 目标之外：回到候选位置，不消耗奖励。
- 拟像术：第一次拖到可复制被动，记录复制对象；第二次再拖进装备槽。第一步不会消耗奖励或删除原牌。
- 新牌仍在下一次有效全局输入后生效，拖拽本身不推进回合。

提示区在拖动时显示具体替换对象，避免手指和卡面盖住槽位名称。辅助按钮放大至144×60，目标区236×164，候选卡放大18%。原有跨裁切线的两种卡面共用同一输入主体。

选牌不暂停棋盘。开始拖动和松手时都检查战斗状态，连杀或结算中不会误装备；切换窗口会取消未完成的拖动。点击卡片、拖到外面、取消选择或收起，都不会扣掉这一组奖励。
