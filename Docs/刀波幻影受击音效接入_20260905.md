# 刀波、幻影与身体受击音效

本次接入 DreadSlash_B、Phantom_B、BodyHurt_B。

- 惊惧斩：方向输入后真正播放刀波时响一次，不随路径每一格重复播放。技能进入待释放状态的原有提示保持不变。
- 次级幻影：选到有效敌人且技能生效后，用 Phantom_B 替换通用技能声；无效目标不播放。
- 身体受击：敌方近战命中 Kait 时使用 BodyHurt_B，不再为同一次近战命中同时播放普通剑击声。敌人之间近战友伤仍保留原普通命中声。

角色语音、卡片音及其他选定音效保持不变。若同一批敌人同时造成多次近战伤害，身体受击声合并播放一次。
