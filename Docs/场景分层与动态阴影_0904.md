# 场景分层与动态阴影

## 本次目标

保留翠绿庭院、双画风、现有棋盘和卡片布局。草坪只作地面；树干、树冠和花草成为独立对象。装饰不参与碰撞，不拦截鼠标和触摸。

从草坪到地砖使用同一个阴影坐标系。树冠轻摆时，投影随轮廓和位置更新。光向统一为从左上投向右下，阴影带一点冷绿色，不使用大面积纯黑。

角色使用脚底接触影，跳跃时变淡、缩小；角色淡出时阴影跟随。石柱增加短投影和接触影。卡片的阴影放在卡面下面，拖起后略微偏移、变软，隐藏时一起隐藏。所有这些视觉变化都不等待游戏回合，也不改变动画播放速度。
