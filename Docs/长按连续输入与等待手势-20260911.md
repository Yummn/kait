# 长按连续输入与等待手势

## 操作

设置新增“长按连续输入”，默认关闭，开启后即时生效。WASD、方向键和屏幕方向按钮均可保持按住；手机滑动一次后不松手，保持本次滑动方向连续操作。松手后停止，需要换方向时重新按键或重新滑动。

保持约0.4秒后允许自动重复，最小间隔0.18秒。自动操作还必须等当前回合表现结束、人物非循环动作播放完成，因此不会靠连发打断出拳。没有排队累积输入；一次无效操作会停止连发。手动操作仍按原来的响应方式处理。

Yummn等待改为在非菜单、非卡牌区域原地按住约0.55秒，一次按住仅等待一次；再次等待要松手重按。允许少量手指抖动，滑动过的触摸不能回到起点冒充等待。等待按钮保留，Kait没有新增等待规则。

后续追加：方向操作击杀敌人后，等回合表现与人物动作结束，再额外停顿0.35秒才恢复自动连按，避免击杀后直接向前冲。保持方向会恢复，松手取消；手动重新按键或换向不受旧停顿限制。键盘、屏幕方向按钮和滑动保持共用该逻辑。专项8/8通过（Logs/kill-pause-tests.xml），Windows构建成功（Logs/kill-pause-build.log）；本改动未重新打Android，未进行本轮运行手感验收。

## 旧手势失效原因

原实现用 `IsTouchOverButton` 排除按钮。但棋盘格为技能选目标也挂了 Button，人物所在格随之被排除，因此“点击Yummn”等待会被挡住。此外还有起止都在人物格、0.4秒内、移动不超过20像素、动画不忙碌等限制。

现在棋盘格加独立标记，正常状态允许滑动/长按穿过这层按钮过滤；技能需要选格时继续保留点击目标语义。真正的菜单和卡牌不触发手势。菜单遮挡、重新开始、失焦、触摸取消及多指触摸会清理相关手势。
