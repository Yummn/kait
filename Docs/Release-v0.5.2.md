# v0.5.2 视听反馈开发快照

这次接着 v0.5.1 往下做，先把目前的源码和素材留一份。主要是补技能状态提示、盾骑士方向提示，以及整理音效节奏，没有另改一套战斗规则。

## 本次变化

- 冰墓接入碎冰束缚 A，随目标位置显示，解冻和死亡后清除。
- 次级幻影接入蝶影印记 B，标识被选中的目标；踏影使用碎影掠地 A 表现起点和落点。
- 盾骑士加入三片盾阵 B，显示实际朝向，正面格挡时短暂亮起，侧背命中不误亮。
- 加入格内裂隙警示与跨盘联动提示代码及检查脚本。这部分仍在构建检查中，按开发中状态归档。
- 惊惧斩蓄势换成 DreadCharge_B，刀波释放仍保留 DreadSlash_B。
- 合成声提前到弹跳开始；近战和法术命中不再等待同批箭矢飞完，箭矢保留飞行后命中的节奏。
- 同类挥剑、施法和蓄力声在 40 毫秒内限制重复播放。法师蓄力提高运行时音量，未修改原始音频文件。
- 输入打断动作时停止对应动作声，保留命中、击杀、角色语音和音乐尾音。

## 验证范围

音效时序调整阶段的 EditMode 测试为 399 项通过，对应安卓包也已构建成功。但这个结果早于后续盾阵和联动提示的全部改动，不能当作本快照全量验收结果。各项特效的阶段验证记录保存在 Docs 中。

本次先归档源码，不附旧的 Windows 或安卓包，避免安装包和标签内容对不上。跨盘提示仍在检查，整体音量尚未做真机混音试听。本版本标为开发快照，继续游玩已发布版本可使用 v0.5.1。

Unity 版本为 6000.0.30f1，打开 Assets/Scenes/Scene.unity 运行。更早的标签保留，仓库已按要求改为公开。Library、日志、本地备份、密钥和构建缓存不上传。
