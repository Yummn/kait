# v0.9.39 Reynard 头像与背景边框预览

## 已接入头像

- 使用内置图像生成工具，基于Reynard现有11202003形象生成透明Q版半身头像。
- 固定白发、黑白长耳、蓝眼、侧辫、黑花饰、斑点白毛领和浅蓝蝴蝶结，采用与Yummn界面一致的大色块、粗线条、轻赛璐璐风格。
- 正式资源：`Assets/Resources/KaitVisuals/ReynardPortrait.png`。
- 状态栏和卡牌大全角色筛选均通过`KaitStorybookDetails`读取同一张头像，避免两处形象不一致。

## 背景与边框候选

预览保存在`ArtPreviews/ReynardBackgroundFrames/`：

- A `A_LavenderShrine.png`：紫藤神社，象牙+梅紫+金角边框，最接近当前Reynard色调。
- B `B_BlueObservatory.png`：蓝月观星庭，蓝灰石框+青色晶体，棋盘识别度最高。
- C `C_MapleTerrace.png`：枫叶露台，酒红木框+奶油内沿，暖色差异最大。

三张都是构图预览，不直接作为最终整张UI贴图。用户选定后将拆成“响应式全屏背景 + 独立九宫格边框”，棋盘和边框分别锚定到布局安全区，从结构上避免手机宽高比变化导致背景开口错位或边框被裁。
