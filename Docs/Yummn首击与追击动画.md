# Yummn 首击与追击动画

2026-09-10

| 情况 | Spine 动画 |
| --- | --- |
| 普通首击 | `01_attack` |
| 普通首击命中、目标未死，等待下一次出拳 | `01_multi_idle_standBy` |
| 不移动，继续攻击同一名敌人 | `01_attack_skipQuest` |
| 击杀 | `01_standBy` |
| 疾风连击等攻击类技能 | `01_multi_standBy` |

击杀表现优先于普通攻击和攻击类技能。疾风连击仍按原规则最多打三拳，但不再绑定专用的待出拳和连击动作。选择疾风连击本身不会进入追击姿态。

移动、换目标、格挡、受伤或击杀会清除相应的追击等待。击杀后跟进到敌人格子保留击杀动作，不强制切跑步；回合结束不截断尚未播放完的一次性动作，下一次有效移动仍能打断。

只修改表现层，不改变伤害、气消耗、击杀回气和敌方行动规则。Kait 的动画映射不变。
