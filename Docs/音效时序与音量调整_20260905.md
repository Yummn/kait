# 音效时序和音量调整

- 合成声跟随合成弹跳开始，不再等 0.14 秒弹跳结束。
- 敌方攻击仍同步起手；0.1 秒后近战和法术先显示命中反馈并播放命中音，箭矢按原飞行时间到达后反馈。没有改动伤害规则或增加输入等待。
- 同一挥剑、施法或蓄力音在 40 毫秒内只播放一次，避免多个敌人同步出手导致重复叠加；不合并不同击杀事件。
- 法师蓄力播放系数由 0.46 提至 2.0，约提高 12.8 dB。只改运行时系数，原始 WAV 不做增益、淡出、归一化或峰值处理。
- 动画被新输入打断时，停止拔剑、挥剑、箭矢飞行、施法和惊惧斩蓄势声。命中、击杀、角色语音、卡片声和音乐继续播放；魔法动作声与魔法命中声拆成独立通道。

本轮没有加入全局限幅器，也没有统一拉高所有声音。叠加控制不能替代真机混音试听，后续仍需检查密集战斗的实际听感。
