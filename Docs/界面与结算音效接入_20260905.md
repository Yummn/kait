# 界面与结算音效接入

这轮确认后接入四条音效：

| 行为 | 选定文件 | 游戏资源名 |
| --- | --- | --- |
| 按钮点击 | ButtonClick_A | ButtonClick_A |
| 无效操作 | 第一轮 Defeat_A | InvalidAction_Defeat_A |
| 胜利结算 | Victory_B3 | Victory_B3 |
| 失败结算 | Defeat_B3 | Defeat_B3 |

胜利和失败均保留完整的 4 秒乐句，没有再次裁剪、淡出、调音量或峰值归一化。按钮和无效操作也直接使用已确认的试听文件。Unity 使用 48 kHz 立体声 PCM，关闭导入归一化。游戏原有混音倍率保持不变，实际游戏听感仍受混音及背景音乐影响。

只替换 GameAudio 的四个资源引用，保留现有触发时机、胜负角色语音及其他音效。原来的 Click_01、Invalid_01、Win_01、Lose_01 文件没有删除，方便回退。

资源位置：Assets/Resources/Audio/UI/SelectedModel。
试听来源：Downloads/kait-sfx-model-audition-20260904/ui_round1 和 ui_round3。
