# Yummn 语音：角色匹配复核

## 结论与边界

本次是设定检索和试听候选，不是接入授权。所有动作最终只用同一角色的语音；保留现有非人声音效。未找到经过核实、同时符合冰系＋狼族＋少女拳斗三项的伊甸园角色，不把名称或外观相似当成设定一致。

108231 对应宫子（万圣节）；本地骨架动画组为 108201。原角色是狼装扮的幽灵少女，喜欢布丁，CV 雨宫天；不是原生冰狼武僧。Yummn 的冰系、气与武僧是项目再设计。

来源：[宫子（万圣节）角色资料](https://priconneredive.gamedbs.jp/chara/show/108201)。

## 建议优先试听 Aqua

本地语音1包存在 Aqua 完整命名声库。阿库娅同由雨宫天配音，作为贴近原角色配音来源的候选，有比之前单纯按时长筛选更明确的依据。但同声优不等于相同声线；阿库娅不是冰狼武僧，不把她的角色设定移植给 Yummn。

来源：[动画官方声优表](https://konosuba.com/1st/staff_cast/)。本次未以可靠官方来源核定这份本地导出包的联动批次，不凭文件名断言具体版本来源。具体台词与听感仍待试听确认。

## 拳斗方向对照 Bridget

布莉基特是比特斗牛犬原型，喜欢特训，技能“最强不败之拳”，CV 阿澄佳奈。拳斗设定较贴近 Yummn，但不是冰系或狼族，而且用户已将这套语音分配给点数32重甲敌人。作为对照，不擅自更换敌人声库，也不默认接受主角和敌人共用声音。

来源：[布莉基特资料](https://wiki.biligame.com/ydydjo/布莉基特)。

## 试听与验证

两段顺序均为普通攻击 N2 → N3 → 技能 H1 → 受击 Hit1 → 开场 Go1 → 胜利 Win1，间隔0.7秒，单段只用同一角色；另核对两套都有 Fail1、Die1 文件。

Aqua 13.54秒，Bridget 11.15秒。工具为 Tools/audition_yummn_voice_roles.py，输出48kHz、双声道PCM16；只拼接预览和采样率转换，不调音高、不变速、不改原件。完成 WAV 解码与输出检查；未做人工听感验收或日文台词核对。不使用上一轮 tiny ASR 的不可靠结果充当翻译。

未修改游戏、Windows、Android、GitHub。选择后再核对短句内容和每个动作映射。
