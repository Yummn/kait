# 惊惧斩 A 与急停烟尘方向修正

## 本次改动

惊惧斩使用选定的“碎月斩压”八帧素材，保留象牙白、浅金边和少量珊瑚色。特效画布为 150×150，放在人物下层，位于被推动敌人的后方。各个敌人的斩压同时出现，沿原有先快后慢的移动曲线跟随，不再逐格延迟播放。

技能伤害、推动范围、Boss 免推规则均未修改。释放音效仍然只播放一次，特效自行淡出，不额外等待动画结束。

实机复查时发现敌人移动替身还带有旧的粉色底板，会遮挡斩压；已改为透明背景，与静止人物保持一致。

上下撞墙烟尘原先带有横向剪切，因此看起来斜着飞。现在改成绕脚底接触点转动 90 度：向上停止时向下拖尾，向下停止时向上拖尾，左右保持原样。此前《边界急停薄尘A接入验证》中关于上下斜向展开的描述已被这次修改替代。
