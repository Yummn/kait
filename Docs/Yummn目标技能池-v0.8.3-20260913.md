# Yummn 目标技能池 v0.8.3

依据：用户提供的《Yummn_目标技能池修改指南_20260913.docx》。本次只升级 Yummn，Kait 的 39 张牌与 3 主动＋3 被动保持不变。

## 牌池

保留原 38 个 ID，调整冬之吐息、碎冰掌、暗影反击、远古奥秘之书；新增 N01～N06、N08～N19，共 56 张（15 主动、41 被动）。普通10、非凡34、稀有12。中间档仍使用蓝色卡框；游戏沿用“罕见”的界面称呼，与本指南“非凡”为同一级。

新增：横扫追击、雷鸣波、碎岩护腕、粉碎音波、镜影术、命令术·出手、法力珍珠、守卫刻文、镜影共鸣、影刃回响、误导术、持久幻影、魔法飞弹、重力摆锤、共鸣水晶、法术回响、丰饶之壶、法师之手。N07不入池。卡牌说明和总气费以 `YummnCatalog.cs` 为准，共用六个任意类型槽位。

## 本次处理的联动

- 拳击与进入/离开范围反击、横扫追击共用拳击流程；每个敌人、每次操作、每种反击独立去重。
- 任何真实破冰都触发碎冰掌，先消耗冻结层再传播伤害。破冰本次免伤，后续独立伤害仍生效。
- 镜影共鸣按攻击编号＋残影编号去重。暗影反击按每个残影或诱饵触发，回气仍保持每次敌人攻击最多1气。
- 持久幻影将自然寿命延长至两个敌方阶段；基础受击会消耗，暗影斗篷可承受多次攻击。
- 误导术仅改变尚未锁定的敌人；命令术只推进指定敌人的一次行动，不追加全体敌方阶段。
- 合成事件统一处理裂隙、奖励、Boss、珍珠和合成攻击。归档支持任意数字满5枚；水晶仅接受本次新合成且仍在盘上的结果；摆锤只允许一次返程。
- 飞弹在同组合成攻击前锁定一个目标，死亡后不换目标；飞弹、刻文和回响不是拳击。
- 丰饶之壶等全部连锁结束才返还，无空格丢弃。返还、袋子删除和法师之手删除都不是合成。
- 法师之手拖出后点右盘数字；只扣总计1气，不滑动、不补2、不触发已有归档，也不推进敌方回合。
