# v0.7：Yummn 双行动模式

这版是在原有 Kait 模式旁边加了一套独立规则，不替换 Kait。主菜单点击开始游戏后先选人物；Kait 仍然用助跑、斩击和连杀，Yummn 使用固定拳力和双行动。角色使用本地素材 108231，导入的是现有 Spine 3.8 数据，不修改原始素材目录。

## 本次内容

- 人物选择、按人物分别续局、按规则分别记录成绩。
- Yummn 的雪庭背景和独立地图。两盘初始障碍都是（行，列）**（1，1）、（5，5）**。新开 Yummn 默认启用副盘柱子，设置里仍可关闭。
- 固定拳力 2，每回合两段；第一段整理一次 2048，后续段只处理人物。最后一段结束才结算敌军、裂隙、新数字和冷却。
- 未击杀停在敌人前，击杀才进入目标格；普通拳不推人、不返还行动、不连锁攻击后面的人。Yummn 模式不产生敌军友伤、裂隙伤害和碰撞伤害。
- 敌军预警、弓手方向和 Boss 盾面在两段之间保持不变。第二段贴墙输入可提前收招，两盘都没响应的首次输入不消耗回合。
- 六张主动、六张被动，加四张共享卡。实验牌和 Kait 专属牌不会进入 Yummn 池。
- 12 张独立图标；延用白银、蓝、金稀有度，以及圆点主动、尖角被动的卡框。跨画风分割线、拖动装备、折叠冷却沿用原有交互。
- 六组冰蓝特效、七个新音效、冰蓝移动残影、剩余行动图标、临时增益图标和 Boss 原地等待标记。
- 四页 Yummn 教程，配规则示意图。Kait 原教程保留。

## 时序与输入

主动只在等待方向时施放，动画结算和敌人阶段不接受技能。每张主动每全局回合至多使用一次。新装备在下一全局回合开始时启用，因此可以在第一段前使用；不会在本回合剩余的一段中途生效。

拳击按“双拳 → 震慑 → 推掌 → 追身”处理，霜息不消耗拳击增益。移位采用约 0.18 秒的先快后慢曲线；命中停顿约 0.035 秒。死亡表现独立，不要求等待死亡动画播完再输入。行动动画中只暂存一个后续方向；结束回合、选牌、换人物会清空暂存。

普通裂隙在创建后的下一回合末结算，占格则取消，不偏移。首次 256 的 Boss 事件不同：玩家占据目标格时保留金色轮廓，之后仍在原格尝试刷新，不吞掉事件。

### 受击白块修复

Yummn 特效原先创建默认白色 Image，直到下一次 Update 才设置贴图；协程在 Update 后创建特效时，画布可能先绘制白色矩形。现在创建时同步绑定贴图和初始缩放，未初始化或缺失贴图时不生成网格，也不会在淡出更新时恢复白色。人物轮廓闪白、特效素材、层级和伤害规则保持不变。
