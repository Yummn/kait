# Reynard 特效审批 03：狐尾获得

本组为待审批预览，尚未接入游戏。三版均为透明4×2、8帧素材，预览GIF每帧95ms。

- A 月光狐尾：月牙火星长成单条白蓝狐尾，最柔和、最像资源获得。
- B 三焰聚尾：三团狐火旋转汇聚为火焰狐尾，能量感最强。
- C 星纱尾迹：银紫星纱勾勒狐尾后结晶破碎，法术感最强。

生成方式：内置 `image_gen`。共同提示要求仅表现象征性狐尾而非完整动物或人物，采用大色块、粗深蓝轮廓、蓝紫月光配色与透明4×2逐帧格式；禁止文字、写实毛发、烟团和粒子噪点。A 强调月光生长，B 强调三焰汇聚，C 强调星纱结晶。

文件：`A-MoonTail.png`、`B-FireTail.png`、`C-StarTail.png` 为透明原图；`A.gif`、`B.gif`、`C.gif` 及 `ABC.gif` 用于审批。
