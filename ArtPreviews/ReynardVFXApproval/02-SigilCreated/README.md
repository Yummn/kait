# Reynard 特效审批 02：法印生成

本组为待审批预览，尚未接入游戏。三版均为透明4×2、8帧素材，预览GIF每帧95ms。

- A 月纹绽放：两弯月弧围合成完整法印，中心以淡紫月光锁定。
- B 狐印落章：狐耳与爪印纹章落下，形成蓝紫色环形涟漪。
- C 星轨书写：四枚星芒沿轨迹写成菱形法印，几何感最强。

生成方式：内置 `image_gen`。共同提示要求参考 Yummn 获批特效的大色块、粗深蓝轮廓、有限层次与透明4×2逐帧格式；禁止文字、人物、烟团、细碎符文和烘焙棋盘格。A 强调月弧成环，B 强调狐印落章，C 强调星轨书写。

文件：`A-MoonSigil.png`、`B-FoxSeal.png`、`C-StarScript.png` 为透明原图；`A.gif`、`B.gif`、`C.gif` 及 `ABC.gif` 用于审批。
