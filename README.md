# Kait

这是我在 2048 原型上继续做的一版滑行战斗 Demo。方向输入会同时作用于左侧战场和右侧数字盘：Kait 在战场上直线滑行，数字盘按 2048 规则移动、合并，并把结果转成裂隙和敌人压力。

现在这版以混合牌池验证主动技能和被动构筑：每次16＋16合成32，获得一组主动、被动混合三选一。拖到对应槽位装备或替换，构筑会影响数字整理、出怪、推动、友伤和技能冷却。

## 运行

当前归档为 `v0.6.1`，包含完整正式牌池、拖拽选牌、漫画教程，以及可移动的双画风选牌控制栏。启动后可以先看教程、调整设置，再开始游戏。详见 [版本说明](Docs/Release-v0.6.1.md)。

- Unity 版本：`6000.0.30f1`
- 场景：`Assets/Scenes/Scene.unity`
- Windows 版可以在 GitHub Releases 下载。完整解压 Windows 压缩包后运行 `kait.exe`，不要单独移动 exe；同目录的 `kait_Data` 和 `UnityPlayer.dll` 都需要保留。
- 安卓安装包为 `kait-v0.6.1.apk`，面向 ARM64、Android 8.0 及以上设备，横屏运行。

打开工程后直接运行场景即可。界面由运行时代码创建，不需要手动替换场景里的旧对象。

## 操作

- `WASD` / 方向键 / 界面方向按钮：移动
- `R`：重新开始
- 鼠标：选择技能、目标和成长
- 方向输入可以打断 Kait 当前动画；敌人死亡和其他场上效果不会锁住移动

## 规则简述

- Kait 会沿输入方向滑行，碰到边界或无法穿透的单位时停止。
- 数字盘与战场共用方向，合成数字后会在对应位置生成裂隙预警。
- 裂隙完成预警后刷新敌人；角色占住危险格时仍会显示提示。
- 撞击敌人会造成伤害，击杀后可以选择新方向继续连杀。
- 敌人按预警移动或攻击，远程敌人采用“瞄准一回合、下一回合攻击”的节奏。
- 每次16＋16合成32获得混合三选一；选择栏不暂停本局，连杀与结算结束后可确认。
- 主动和被动各3槽，新牌在下一次有效全局输入生效。主动向下装备，被动向上装备；主动技能拖入战场使用。
- 生命归零失败，击败盾骑士 Boss 获胜。

## 代码位置

- `Assets/Scripts/KaitCore.cs`：棋盘、回合、敌人、伤害和技能规则
- `Assets/Scripts/KaitPassives.cs`：被动牌资料、分类和一句话说明
- `Assets/Scripts/KaitGame.cs`：输入、UI、动画和运行时表现
- `Assets/Scripts/KaitMainMenu.cs`：主界面按钮、布局、安全区适配和按下反馈
- `Assets/Tests/Editor`：规则与资源检查
