# Kait：2048 式滑行战斗 Demo

这是从原 2048 项目另存出的独立 Unity 工程。当前版本依据《凯特 MVP 落地实现文档 v0.1》实现核心验证玩法。

## 运行

用 Unity 6.0.30f1 打开本目录并运行 `Assets/Scenes/Scene.unity`。运行时会自动切换到 Kait 界面，不需要手工替换场景对象。

## 操作

- `WASD`、方向键或界面方向按钮：同时控制凯特滑行与 4×4 威胁盘。
- `R` 或“重新开始”：开始新一局。
- 凯特会沿方向持续滑行，直到墙、幻影或无法穿透的敌人令她停下。
- 威胁盘每个有效回合新增一个 2；合并会在战斗盘产生裂隙预告，下一有效回合后生成敌人。
- 首次达到 4、8、16 时，可在右侧点击解锁战技。

## 已实现

- 3 张随机 9×9 灰盒地图，外围固定墙。
- 4×4 标准压缩/合并规则与共享方向输入。
- 穿透阈值、连续击杀、无效贴墙输入不消耗回合。
- 杂兵、盾卫、弓手及可读的行动意图。
- 凯特逐格滑行、碰撞停顿、击杀闪光、敌人平移、攻击扫格、威胁块滑动合并、数字刷新和裂隙/敌人弹出动画。
- 凯特与威胁盘在同一阶段同步快速滑动；之后所有敌人同时移动或攻击，不再逐个等待。
- 凯特经过裂隙不会将其消除；裂隙只会在预告结束并转化为敌人时消失。
- 青色战场格表示敌人的移动目标，红色格表示近战或射线攻击范围；敌人格中的箭头表示下一步方向。
- 盾卫、弓手与精英分别需要至少 4、3、6 格蓄力距离才可穿透，短距离碰撞会停在敌人前方。
- 生成预告、Preparing 状态和延迟攻击。
- 咒剑诅咒、次级幻影、惊惧斩三种规则型战技。
- 威胁盘锁死/凯特被击中的结算界面。
- 每局 CSV 日志，保存在 `Application.persistentDataPath`。

## 代码入口

- `Assets/Scripts/KaitCore.cs`：纯规则、回合、棋盘、敌人、技能。
- `Assets/Scripts/KaitGame.cs`：运行时 UI、输入、表现与日志。
